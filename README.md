# Bole(伯乐)

> **千里马常有,而伯乐不常有——现在有了。**

Bole 是装在 [Claude Code](https://claude.com/claude-code) 里的开源求职助手:自动发现职位、打分筛选,并基于**你确认过的真实经历**,为每一个 JD 量体裁衣地生成定制简历、求职信与投递指引。不海投,不捏造。

> 🚧 **项目状态**:v0.1–v0.3 完整规格已冻结,代码建设中(见文末路线图)。

---

## ⚡ 最简上手(三步)

**前提**:已安装并登录 [Claude Code CLI](https://claude.com/claude-code)(用你自己的订阅,任何型号均可);Python ≥ 3.10。

```bash
git clone https://github.com/RAGG3D/Bole-.git bole
cd bole
claude
```

进入 Claude Code 后,依次输入三个命令:

| 步骤 | 命令 | 它做什么 |
|---|---|---|
| 1 | `/doctor` | 环境体检:逐项检查,缺什么给中文修复指引,**不静默安装任何东西** |
| 2 | `/setup` | 采访式建档:分五轮问你经历/技能/红线/求职意向,逐条确认后写入本地"事实台账" |
| 3 | `/scan` | 扫描职位 → 打分分档 → 为匹配岗生成定制 CV/求职信 PDF + 每岗一份中文投递指引 |

跑完打开 `Applications/` 文件夹:每个匹配职位一个文件夹,内含 JD 全文、定制简历 PDF、定制求职信 PDF,和一份告诉你**怎么投、薪资填多少**的 README。照着投就行。

第四个命令 `/apply`(自动投递)默认关闭,见下文「自动投递」一节。

## 这是什么

**一句话:一个 Claude Code 技能包(skill repo),不是网站、不是后端服务。** 你把仓库 clone 下来,在文件夹里跑 `claude`,Claude 读仓库里的指令与脚本替你干活;你的数据全部留在你自己的电脑上。

### 名字来历

"世有伯乐,然后有千里马。千里马常有,而伯乐不常有。"求职市场的现实是:千里马很多,但简历在招聘方六秒的浏览里没被看见。Bole 做的事,就是给每一份 JD 配一次"相马"——读懂它真正要什么,再把你**真实拥有**的对应能力剪裁到台前。

### 三个立身原则

1. **事实台账是唯一事实来源**。`/setup` 采访时你逐条确认过的经历、技能、数字成果,构成本地的 `profile/facts.json`。生成任何材料只允许引用台账里的事实——**结构上不可能捏造**;出 PDF 前还有一个确定性扫描器强制把关。
2. **红线机制**。建档时会明确问你"哪些技能你没有、绝不能写"(比如没用过 Power BI、没做过湿实验)。红线词一旦出现在生成材料里,扫描器直接拒绝出 PDF。
3. **诚实缺口句**。对弱匹配职位,求职信里会有**恰好一句**平静、不卑不亢的真实差距说明,随后衔接你的可迁移能力——不装完美,也不自贬。

## 它不是什么

- ❌ 不是海投机器人——每轮只为高匹配岗生成材料,有生成上限;
- ❌ 不会"美化"或编造经历——见上面的台账与红线机制;
- ❌ 不破解验证码、不绕机器人墙——遇到就转人工,没有例外;
- ❌ 不代做在线测评/视频面试/性格测试;
- ❌ 不碰你的密码——任何登录/注册都由你本人在浏览器里完成。

## 工作原理

```
免费公开通道发现职位(LinkedIn 访客接口 / Workday / Greenhouse / Lever / Ashby / 手贴 JD)
        │
        ▼
台账去重 → 机械分诊:正则分桶,把资深岗/资格不符/红线岗先筛掉 —— 省的是你的 token 额度
        │
        ▼
Claude 逐岗读全文 JD 打分(0-100):资格闸门 → 资历封顶 → 红线核对 → 分档归档
        │                        Tier 1 (80+) / Tier 2 (70-79) / Tier 3 (<70)
        ▼
生成材料(只引用事实台账)→ 红线扫描(不过不出 PDF)→ 本机浏览器打印 PDF(零重依赖)
        │
        ▼
每岗 README:得分与理由、推荐薪资(数字+币种+理由)、该 ATS 的已知坑、表单答案速查
```

打分有几条硬规则值得知道:资深岗(Senior/Lead+)有分数封顶且**永不生成材料**——投不该投的岗浪费所有人的时间;要求公民/PR/安全许可而你不符的岗直接跳过;LinkedIn 的残缺 JD(stub)会被标记,提醒你投前核对完整职位描述。

## 自动投递(v0.2,默认关闭)

`/apply` 可以把投递包里"干净 ATS"(实测可自动投:Greenhouse / Ashby / HiBob / Oracle / Workday)的岗位,交给 OpenClaw 浏览器代理自动提交。设计要点:

- **默认关闭**;开启后每轮投递前仍要你确认清单(确认策略可调);
- 招聘站的登录/注册一律**你本人**在浏览器里完成——Bole 不接收、不存储、不代输任何密码,唯一例外是邮箱验证码(OTP)由你转达;
- **超时 ≠ 失败**:提交超时后先核实实际状态再决定续跑,同一职位**永不盲目重投**(防双投);
- 有墙的平台(Phenom / SuccessFactors / HireBridge / 纯 Easy-Apply)不硬闯,保持手动投递包;
- ATS 能力地图 `data/ats_map.json` 随仓库分发,来自实测经验,欢迎社区 PR 持续更新。

## 隐私与安全

- 你的个人资料(`profile/`)、生成材料(`Applications/`)、运行状态(`state/`)全部**只存本地**,已写入 `.gitignore`,永不入库;
- 不发送任何遥测;
- 免登录抓取遵守礼貌规则(限速、退避、绝不携带 Cookie);LinkedIn 访客接口属 ToS 灰区,已内置限速并默认优先公司直连 ATS,请自行评估(见免责声明)。

## 支持的职位来源

| 来源 | 方式 | 说明 |
|---|---|---|
| LinkedIn | 访客接口,无需登录 | 含 junior 岗召回增强;残缺 JD 自动标记 |
| Workday | 公开 JSON | 在 config 里配置目标公司站点 |
| Greenhouse / Lever / Ashby | 公开职位板 JSON | 在 config 里配置公司 token |
| 公司官网直投页 | URL 抓取 | 含机器人墙检测,遇墙转人工队列 |
| SEEK | 手贴 JD | 无免费接口;复制粘贴进来,后续流程完全一样 |

## FAQ

**要花钱吗?** 仓库零付费依赖。消耗的只有你自己 Claude 订阅的额度;打分默认走"省额度模式"(先机械筛掉大部分,再小批量打分)。

**会编造我的经历吗?** 不会,而且是"结构上不会":材料只能引用你确认过的事实台账,红线扫描不通过就不出 PDF。

**为什么不自动抓 SEEK?** SEEK 没有免费公开接口。手动复制 JD 粘贴进来即可,打分与生成流程完全一样。

**只适用于澳洲吗?** 不。默认配置以墨尔本为例;地区、关键词、薪资参考区间(内置 AU/US/UK/SG)都可配置。

**Windows 能用吗?** 支持 Linux / macOS / Windows(建议 WSL2)。

**有英文版吗?** v0.3 提供英文 README 与 `ui_language` 配置;生成的简历/求职信本就默认英文(可改)。
